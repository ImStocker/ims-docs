# About IMS Creators

Glad to welcome you, dear users. Here is the basic information about working with [IMS Creators](https://ims.cr5.space/en) - a web application that will help you release your game and announce it to the world! 

**IMS Creators** is your personal assistant that allows you to:

1. Easily and conveniently maintain a game design document.
2. Export game parameters from a game design document to engines.
3. Quick new team member on-boarding.
4. Estimate the complexity of both the entire product and its individual parts.
5. Manage the workflow using task boards.
6. Post development news in the game pulse and receive feedback from future players.

Our advantages:

- 📝 Game Design Document (GDD) Maker
- 🤝 Smarter Team Coordination
- ⚙️ Engine-Ready Parameter Export
- ✍️ Devlog publishing

Everything you need in one place 😉
