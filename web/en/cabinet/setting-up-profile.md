# Setting up a profile

The user can add the date of birth and specify the native language.

![Personal data](../images/personal_data_en.png)

There are 2 settings available in the `Notifications` section:

- Subscribe to the IMS Creators Newsletter
- Notify me about changes to projects I'm subscribed to
- Notify me about likes and comments on my posts

![Notifications](../images/notifications_settings_en.png)
