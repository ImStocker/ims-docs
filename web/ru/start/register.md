# Регистрация нового пользователя

**Шаг 1**

Перейдите на страницу [Регистрация](https://ims.cr5.space/app/sign-up).

- Заполните поля `Email`, `Имя пользователя`, `Пароль`.
- После чего `Повторите пароль` и кликните `Зарегистрироваться`.
- Необходимо поставить галочку рядом с полем "Согласен с [правилами](https://ims.cr5.space/ru/terms) и [политикой конфиденциальности](https://ims.cr5.space/ru/privacy)".
- По желанию можно `подписаться на новостную рассылку`.

![Регистрация](../images/register_ru.png)

**Шаг 2**

Для завершения регистрации необходимо подтвердить почту, перейдя по ссылке из письма, которое придет на указанный email.

**Шаг 3**

После регистрации можно входить в систему в любое время. Для входа требуется указать `Email`, `Пароль` и кликнуть `Войти`.

![Вход](../images/login_ru.png)
