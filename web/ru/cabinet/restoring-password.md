# Восстановление пароля

Если Вы забыли пароль, то его можно легко восстановить. На форме входа/регистрации кликните на `Забыли пароль?` или сразу перейдите по [этой ссылке](https://ims.cr5.space/app/restore). Введите свой email, чтобы получить письмо. Перейдите по ссылке из письма и придумайте новый пароль.
