# Start Screen

When you launch the program, the **start screen** opens, serving as the entry point for all operations. The following options are available:

* **Create new project** – start from scratch or based on one of the built-in templates.

* **Open existing folder as project** – select any folder on your computer; the program will treat its contents as a project (all nested items will become available in the project tree).

* **Open cloud project** – load a project previously saved to the cloud. After loading, it becomes available as a local project for further work.

* **Switch theme** – toggle between **dark** and **light** interface themes.

* **Select language** – you can change the interface language.

If you have already worked in the program, the left side of the start screen will display a list of **«Recently opened projects»**. You can click on any of them to quickly resume work.
