# **Export**


Right-click on any element (or click the three dots next to it) and select **«Export»**. The following options are available:

* **Markdown (.md)** – export to text format with Markdown markup. Convenient for publishing documentation or inserting into a wiki.

* **PDF (.pdf)** – export to PDF document (preserves formatting, suitable for printing and distribution).

* **JSON (.json)** – export to the system's native format (full copy of internal data, matches the format stored on disk).

> **Important:** The JSON format fully matches the internal representation of the element. It can be used for backup, importing back into the system, or for integration with engines that support JSON reading. If standard JSON is insufficient, create a **custom format export** — [see «Export to Custom Format» section](../integration/export-format_en.md).
